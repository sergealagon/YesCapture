
# YesCapture
YesCapture is a jailed tweak that allows you to freely use screen recording on apps that detects it.
Simply inject the dylib to an app of your choice using a tool of your choice (Feather, Sideloadly, TrollFools, etc)
Works on LiveContainer as well.
